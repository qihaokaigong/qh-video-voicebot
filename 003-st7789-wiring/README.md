## 视频中的七根线

视频使用 ESP32-S3 和 GMT130 屏幕，介绍了七个引脚的基本作用：

| 引脚 | 作用 |
| --- | --- |
| VCC | 供电 |
| GND | 接地 |
| BLK | 背光控制 |
| RES | 屏幕复位 |
| SCK | SPI 时钟 |
| SDA | SPI 数据 |
| DC | 数据与命令选择 |

实际 GPIO 分配应以所用开发板、屏幕模块和程序配置为准。
